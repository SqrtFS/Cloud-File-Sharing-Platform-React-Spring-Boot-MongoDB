# Cloud File Sharing Platform

A full-stack cloud file sharing application built with React, Spring Boot, and MongoDB.

## 🛠️ Tech Stack

- **Frontend:** React.js, Axios
- **Backend:** Java 21, Spring Boot
- **Database:** MongoDB

---

## ⚙️ Environment Setup

You need to configure environment variables to run the project. 

### 1. Backend Setup (`backend/.env`)
Create a `.env` file in the **root folder of the backend project** (where `pom.xml` or `build.gradle` is located).

### 2. install dependencies for frontend

npm install axios lucide-react react-router-dom react-hot-toast stompjs sockjs-client

### 3. run project

backend run :  mvn spring-boot:run
frontend run : npm run dev
